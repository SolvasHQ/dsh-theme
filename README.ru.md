Палитры тем, полноценный DIY-редактор цветов, библиотека именованных пользовательских
тем, локальные шрифты и размер текста для веб-интерфейса
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Открывается
значком палитры в левом нижнем углу боковой панели.

Светлая и тёмная темы равноправны: у каждого пресета и каждого DIY-цвета есть
значения для обоих режимов, поэтому всё работает при переключении оформления
системы между светлым, тёмным и автоматическим.

## Возможности

- **14 пресетов**: По умолчанию, Тёплая, Моно, Claude, Claude+, Киноварь, Янтарное
  моно, MX Brutalist, Tiesen, Vescrow, **Catppuccin, Nord, Gruvbox и Tokyo Night**, а
  также карточка **Своя тема**.
- **DIY-редактор**: для светлого и тёмного режимов отдельно — фон, карточка,
  всплывающее окно, боковая панель, текст, граница и акцент режима; цвета состояний
  сохраняются по режимам; переключатель **Жирные границы**. Неизменённые поля
  выводятся автоматически.
- **Точное наследование пресета**: при выборе пресета копируются все 14 якорей обоих
  режимов и его особенности, например жирные границы у MX Brutalist.
- **Именованные темы**: сохраняйте под именем, переключайтесь в **Мои темы** (активная
  отмечена ✓), в режиме **Управление** выбирайте несколько, удаляйте или
  экспортируйте.
- **Импорт/экспорт JSON**: экспорт одной темы или набора в `.json`; импорт вставкой
  JSON или выбором файла. В диалоге есть пример с комментариями; импортированные темы
  появляются в **Мои темы** с именем из поля `name`.
- **Шрифты**: отдельные наборы для латиницы, китайского и кода. В каждом меню —
  встроенные варианты и **шрифты, прочитанные с этого компьютера** (`Локальный ·`),
  их можно скрыть и обновить кнопкой **Найти локальные шрифты**; совпадения с
  пресетами разрешены.
- **Размер текста**: 10–22 px через нативный сервис темы, сохраняется после перезагрузки.
- **Восемь языков**: упрощённый китайский, английский, японский, испанский,
  французский, немецкий, русский и бразильский португальский.
- **Сохраняется после перезапуска**: настройки хранятся в документе Host-настроек DSH.

## Установка

### Discover (рекомендуется)

1. Откройте **Plugins → Discover**.
2. Добавьте источник индекса:

   ```
   https://cdn.jsdelivr.net/gh/SolvasHQ/dsh-theme@v1.5.0/market/index.json
   ```

3. Найдите **DSH Theme**, откройте карточку и нажмите **Install**.

Индекс привязан к Git-коммиту версии 1.5.0. Эта же версия опубликована в npm как
`@solvashq/dsh-theme@1.5.0`; в GitHub Release приложен `dsh-theme.tgz`.

### npm

```bash
npm install @solvashq/dsh-theme
```

Либо попросите агент DSH установить `@solvashq/dsh-theme@1.5.0`.

### Из исходников

```bash
git clone https://github.com/SolvasHQ/dsh-theme.git
cd dsh-theme
pnpm install --prod
```

Добавьте каталог в список bundle вашего профиля DSH (лучше через Plugin Manager с
абсолютным путём), выполните `pnpm install` в профиле и перезапустите DSH.

## Совместимость

Проверено на DeepSeek Harness для компьютера `0.2.2-rc.1` (Web GUI); линейка
0.2.1-rc.2 также работает. Плагин использует только публичные точки расширения
клиента (`slots`, `theme`, `locale`, `configForms`) и volatile-конфигурацию Host.

## Благодарности за палитры

Catppuccin, Nord, Gruvbox и Tokyo Night — палитры сообщества, созданные их авторами.
Они используются как цветовые ориентиры, отображённые на 14 якорей DSH с коррекцией
контраста; ссылки находятся в `research/palettes.json` в `sources`, действуют
лицензии соответствующих проектов.
